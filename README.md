PyMosh is a simple glitch art creation / image editing program, made with Python, Tkinter, and Pillow. 
It has various effects to use, searchable by code or name.

It also allows code paramaters, IE typing 1:1 will execute a horizontal rgb shift of 1 px, whereas 1:100 will do the same but with 100 pixels.
Some effects even have multiple paramaters which can be accessed by cod:param1:param2...

Pressing the effects button opens a screen that shows each effect, it's code, and any aliases, as well as a description of what it does.
